# Chernichniy_pirog
Данный скрипт предназначен для автоматического определения операционной системы, на которой он запущен, сбора основных параметров текущей системы и сохранения полученной информации в файл формата JSON.
В начале работы программа определяет операционную систему с помощью стандартного модуля platform. Скрипт поддерживает работу в трёх основных операционных системах: Windows, Linux и macOS.

После определения ОС программа собирает основные сведения о системе: название и версию операционной системы, номер её выпуска, архитектуру процессора, информацию о процессоре, имя компьютера и имя текущего пользователя. Также дополнительно собирается информация об используемой версии Python, реализации Python и пути к исполняемому файлу интерпретатора.

Для получения текущего рабочего каталога используется модуль os, а для получения имени компьютера — модуль socket. Текущая дата и время запуска программы определяются с помощью модуля datetime.

Собранные данные объединяются в единую структуру Python в виде вложенного словаря. После этого с помощью стандартного модуля json информация записывается в файл system_info.json. Параметр ensure_ascii=False позволяет корректно сохранять символы кириллицы, а indent=4 делает структуру JSON удобной для чтения.

Для выполнения лабораторной работы используются только стандартные модули Python. Внешние библиотеки не применяются, поскольку их использование не требуется: стандартных средств Python достаточно для определения ОС и получения необходимых системных параметров. При этом скрипт не использует системные утилиты Windows, Linux или macOS, что соответствует условию лабораторной работы.

Таким образом, результатом работы программы является JSON-файл, содержащий структурированную информацию о текущей операционной системе, компьютере и среде выполнения Python.
